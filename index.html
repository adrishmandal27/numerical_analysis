JavaScript Mathematical Syntax Guide

Use these standard formats when typing expressions into the f(x) input fields across Root Finding, Integration, and Graphing modules.

Basic Arithmetic & Powers

  • Addition: x + 3
  • Subtraction: x - 5
  • Multiplication: 3*x (explicit '*' required)
  • Division: x / 2
  • Exponents:Math.pow(x, n) where n is the exponent

Trigonometric Functions

  • Sine: Math.sin(x)
  • Cosine: Math.cos(x)
  • Tangent: Math.tan(x)

Advanced Math Functions

  • Square Root: Math.sqrt(x)
  • Exponential: Math.exp(x) *(e^x)*
  • Natural Log: Math.log(x) *(ln x)*
  • Absolute Value: Math.abs(x)

Mathematical Constants

  • Pi (π): Math.PI *(e.g., Math.PI / 2)*
  • Euler's Number (e): Math.E
💡 Example Function: Math.sin(x) + Math.pow(x, 2) - 4*x + Math.PI
